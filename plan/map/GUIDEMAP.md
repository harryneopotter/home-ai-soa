## 1. The Idea (Vision)

**"Son of Anton" (SOA1)** is a strictly local, privacy-first home AI assistant designed to run on consumer hardware without any cloud dependencies.

### Core Philosophy
1.  **Zero Data Leakage**: No data leaves the physical machine. No cloud APIs, no telemetry.
2.  **Consent-Based Autonomy**: The agent is capable but constrained. It proposes actions (e.g., "Shall I analyze your finances?"), but **never** executes sensitive tasks without explicit user confirmation. "Silence ≠ Consent".
3.  **Natural Interaction**: Responses are generated by an LLM (Orchestrator), not hardcoded strings, ensuring fluid and context-aware communication.
4.  **Specialization**: A generalist Orchestrator delegates complex tasks to specialized sub-agents (e.g., Finance, Calendar) only when needed.

## 2. Implementation & Architecture

### Hardware Stack
-   **Server**: Local workstation (Intel i5-12600K, 128GB RAM).
-   **Compute**: 2x NVIDIA RTX 5060 Ti (16GB VRAM each).
-   **Network**: Tailscale (Secure VPN) for remote access.

### Software Stack
-   **Backend**: Python 3.10+ with **FastAPI**.
-   **Frontend**: HTML5/JS with Jinja2 templates (rendered via FastAPI).
-   **AI Engine**: **Ollama** managing local models.
    -   *Orchestrator*: `NemoAgent:latest` (GPU 0).
    -   *Specialist*: `phinance-json:latest` (GPU 1).
    -   *Insights*: `qwen2.5:7b-instruct` (Shared).
-   **Memory**:
    -   *Current*: **MemLayer** (Simple vector store).
    -   *Planned*: **MemGraph** (NetworkX + ChromaDB).
-   **Database**: SQLite (`finance.db`) for structured data persistence.

### High-Level Architecture
```mermaid
graph TD
    User[User (Web/Chat)] --> API[SOA1 API (FastAPI)]
    API --> Agent[SOA1 Agent (Orchestrator)]
    Agent -->|Retrieves Context| Memory[MemLayer/MemGraph]
    Agent -->|Inference| Ollama[Ollama LLM Server]
    
    subgraph "Progressive Pipeline"
        Agent -->|Detects Intent| BP[Batch Processor]
        BP -->|Extracts Data| Parser[Regex/State Machine]
        BP -->|Calculates Math| PyCalc[Python Financial Calc]
        BP -->|Generates Insights| Phinance[Phinance Model]
    end
    
    BP -->|Persists| DB[(SQLite DB)]
```

### Hybrid Calculation Engine
To solve LLM innumeracy, SOA1 uses a hybrid approach:
-   **Python**: Calculates ALL numbers (totals, averages, sorts). **100% Accurate.**
-   **LLM**: Generates qualitative insights, identifies patterns, and formats narrative.

## 5. User Flow: The Progressive Pipeline

1.  **Ingestion (Immediate)**:
    -   User uploads PDFs.
    -   System extracts metadata (page count, institution) in <500ms.
    -   **LLM Response**: "I see 3 Apple Card statements. Shall I analyze them?" (No analysis yet).

2.  **Consent (Gatekeeper)**:
    -   User clicks "Run Detailed Analysis" (or types "Yes").
    -   Agent detects intent, grants consent (`consent_granted=True`), and spawns background thread.

3.  **Analysis (Background Async)**:
    -   **Extraction**: Regex/State Machine parses transactions from text.
    -   **Persistence**: Transactions saved to DB (Only NOW, after consent).
    -   **Calculation**: Python computes totals, top merchants, categories.
    -   **Insight**: Phinance (LLM) reviews data for anomalies/recommendations.
    -   **Output Prep**: JSON, PDF command, and Image prompts are pre-generated.

4.  **Delivery (Instant)**:
    -   Agent notifies user: "Analysis complete! Found $3k in spending. How do you want the report?"
    -   User selects "Web Dashboard".
    -   System serves the pre-generated JSON immediately.

## 6. Guardrails & Security

### Privacy & Persistence
-   **Local Storage**: All files in `finance-agent/data/uploads`. Database is `finance.db`.
-   **Redaction**: PII (CC numbers, SSN) masked in logs via `RedactingFormatter`.
-   **Compression**: Extracted text stored as GZIP blobs to save space.

### Operational Safety
-   **Rate Limiting**: Token bucket algorithm prevents abuse/overload.
-   **Input Validation**:
    -   Max file size: 10MB.
    -   Max message length: 10,000 chars.
    -   Path traversal protection on file endpoints.
-   **VRAM Management**: Agents must check `HARDWARE_SPECS.md` before loading models to prevent OOM.

### AI Safety
-   **Consent Enforcement**: `orchestrator.py` ensures specialists never run on "autopilot".
-   **Hallucination Check**: Hybrid architecture prevents LLM from doing math.
-   **Retry Logic**: `tenacity` retries failed model calls (up to 3x) with exponential backoff.
